## 쓰는 법

- 화면마다 **목적 · 보이는 것 · 할 수 있는 것 · 쓰는 API · 규칙**을 적는다.
- 화면 번호(T01, L02 등)는 코드 주석과 테스트 이름에 같이 쓴다.
- 정해지지 않은 것은 문서 끝 **할 일·미정**에 적는다. 구현하면서 정한 것은 그 자리로 옮긴다.
