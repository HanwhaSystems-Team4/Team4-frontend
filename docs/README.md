# 문서 안내

| 폴더·파일 | 무엇을 적나 | 언제 적나 |
| --- | --- | --- |
| `docs/decisions/` | **결정 기록**. 후보들을 비교하고 왜 그것을 골랐는지 | 라이브러리·구조·화면 흐름·API 연동 방식처럼 나중에 "왜 이렇게 했지?"가 나올 결정을 할 때 |
| `CHANGELOG.md` (루트) | **업데이트 기록**. 버전·날짜별로 무엇이 바뀌었는지 | PR을 머지할 때마다 `Unreleased`에 한 줄, 발표·데모 시점에 버전으로 묶음 |

## 규칙

- 결정 기록은 `_template.md`를 복사해 `NNNN-제목.md`로 만든다. 번호는 1씩 늘린다.
- 결정을 바꿀 때는 기존 파일을 지우지 않고, 새 기록을 만든 뒤 기존 기록의 상태를 `대체됨(→ NNNN)`으로 바꾼다.
- PR 설명에 관련 결정 기록과 CHANGELOG 항목을 링크한다.
