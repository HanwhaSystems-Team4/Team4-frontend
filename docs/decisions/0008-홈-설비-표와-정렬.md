# 0008. 홈을 설비 표로 보이고 정렬 드롭다운을 둔다

- 상태: 제안
- 날짜: 2026-10-27
- 작성: 문선웅
- 관련: [0007](0007-AB-테스트-후보-재구성과-산업-관제형.md), UI 컨셉 시안 03 "알람 · 목록과 선택 상세"

## 배경

UI 컨셉 시안 03의 핵심은 화면 배치다. 시안은 알람을 "무엇이 울리는가"를 보여 주는 표(우선 · 설비 · 증상 · 값 / 경계 · 발생 · 상태)로 보이고, 정렬을 바꿀 수 있다.
요청: 홈을 알람 목록이 아니라 **설비 표**로 보이고, 정렬은 드롭다운(발생순 · 이름순 등)으로, 기본은 최신 발생 순서로, 이상 없는 설비는 반투명으로.

## 가능한 범위

홈 API(`GET /api/tech/home`)의 알람 행에는 설비 번호, 증상군 이름, 알람 값 · 단위 · 경계 · 방향, 발생 시각, 상태(새 알람 · 진행 중 · 완료), 진행(점검 n / 최대 m)이 있다. 표의 열은 이 값만으로 채운다.
**알람이 없는 설비(이상 없는 설비)의 목록은 API에 없다.** 그래서 반투명 행은 "처리를 마친(완료) 설비"에 쓴다. 알람이 없는 설비까지 보이려면 설비 전체 상태 API가 필요하다(백엔드 레포는 수정하지 않는다).

## 후보

| | 가. 모든 후보 화면을 표로 | 나. 표 마크업은 항상 넣고 C에서만 보임 |
| --- | --- | --- |
| 하는 일 | A · B · E 홈도 표로 바뀐다 | 값 · 머리 줄 · 정렬 칸을 항상 그리되 C 외에는 CSS로 숨김 |
| 원래 화면 | 바뀜(비교 기준이 흔들림) | 그대로 |
| 화면 테스트 | 새 구조에 맞게 많이 고침 | 기존 시험 그대로 통과 |

## 결정

**나.** 알람 행(`.al`)의 기존 마크업은 그대로 두고 값 칸(`.al-v`) · 표 머리(`.al-head`) · 정렬 드롭다운(`.al-sort`)을 더한다. 산업 관제형(C)에서만 보이고, A · B에서는 숨겨져 지금 화면과 같다.

- 정렬 드롭다운: 상태순 · 발생순(최신 먼저) · 이름순. 기본은 상태순이고, C에서는 발생순으로 시작한다.
- 반투명: 상태가 완료인 행(`data-status="done"`)은 C에서 반투명.
- 표 열: 상태(NEW · RUN · DONE) · 설비 · 증상 · 값 / 경계 · 발생 · 진행 · 버튼.
- 화면은 API가 준 값만 보인다. 값 · 경계 · 방향은 응답 문자열을 그대로 쓴다.

## 다시 검토할 조건

- 설비 전체 상태 API가 생기면 알람이 없는 설비도 반투명 행으로 더하고, 시안의 설비 타일 지도를 만들지 정한다.
- 시안의 담당자 · 경과 열은 API에 없어 넣지 않았다. API가 주면 더한다.
