# 0003. 디자인 변경 범위를 색 · 테두리 · 글꼴로 한정

- 상태: 결정됨
- 날짜: 2026-10-19
- 작성: 문선웅
- 대체: 0002의 화면 틀 · 배치 변경 부분

## 배경

0002에서 스타일 파일을 새로 쓰면서 색뿐 아니라 화면 틀(고정 크기 → 브라우저 전체), 본문 최대 폭, 모달 위치, 파트장 사이드바 폭, 좁은 화면 한 열 배치 같은 UI 배치까지 바뀌었다. 원래 의도는 색 · 크기감 · 테두리 같은 겉모양만 바꾸고 UI 구조는 그대로 두는 것이었다.

## 후보

| | A. 0002 그대로 | B. 원래 스타일 위에 테마 파일을 덧씌움 | C. 0002 파일에서 배치만 손으로 되돌림 |
| --- | --- | --- | --- |
| UI 구조 | 바뀐 상태 | 원래와 같음(원래 파일이 배치를 정함) | 되돌린 만큼만 같음 |
| 같은지 확인 | — | 원래 파일의 위치 · 크기 값이 그대로라 비교 쉬움 | 규칙마다 비교해야 함 |
| 이후 수정 | 한 파일 | 배치 = 원래 파일, 색 = `theme.css`로 나뉨 | 한 파일 |

## 결정

**B.** 원래 스타일 세 파일(`guide-a.css`, `direction-guide.css`, `past-adjust.css`)을 되살리고, 그 안의 색 값만 대시보드 팔레트로 바꿨다. 그 뒤에 `theme.css`를 불러와 색 · 테두리 모양 · 글자 굵기 · 강조 지점만 덧씌운다.

## 바뀌는 것 / 바뀌지 않는 것

| 바뀜 (`theme.css` · 색 값) | 그대로 (원래 파일) |
| --- | --- |
| 색: zinc 회색, 주황 강조, 검정 주 버튼, 밝은 파트장 사이드바 | 화면 틀: 정비자 1080 × 740, 파트장 1280 × 620 |
| 글꼴: Pretendard, 굵기 900 → 700 | 요소 위치 · 크기 · 간격 · 격자 · 모달 위치 |
| 테두리: 카드 그림자 제거, 모서리(카드 12px, 버튼 6~8px, 칩 둥근 알약), 안내 띠 1px 안쪽 테두리 | 화면 구성 · 순서 · 클래스 이름 |

## 영향

- 되살림: `packages/ui/src/styles/guide-a.css` · `direction-guide.css` · `past-adjust.css` (색 값만 바뀜), 두 앱의 `app.css`, 정비자 로그인 화면 고정 높이
- `theme.css`는 덧씌우는 파일로 다시 작성
- 화면 테스트 85개 그대로 통과
