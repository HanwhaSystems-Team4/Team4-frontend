# 0007. A/B 테스트 후보를 A · B(플로팅 벤토형) · C(산업 관제형)로 재구성

- 상태: 결정됨
- 날짜: 2026-10-27
- 작성: 문선웅
- 대체: [0004](0004-AB-테스트용-디자인-후보-3개.md)의 후보 구성(B 현장 터치형 · C 업무 도구형 · D 플로팅 벤토형). 전환 방식(CSS 덧씌우기 + 전환 막대)은 그대로 쓴다.
- 관련: UI 컨셉 시안 `03_Industrial_Operations.pdf`, [0005](0005-다크-모드-기능.md), [0006](0006-AB-테스트용-글꼴-후보.md)

## 배경

UI 컨셉 시안 5종 가운데 3번 "Industrial Operations(산업 관제형)"이 마음에 든다는 의견이 나왔다.
이에 테스트 모드 후보를 다음처럼 바꾼다.

- 기존 B 현장 터치형, C 업무 도구형을 **제거**한다.
- 기존 D 플로팅 벤토형을 **B로 옮긴다**(디자인은 그대로).
- 3번 시안을 **새 C**로 만든다.
- A(현재 버전)와 E(조장님 레포 원본, 새 탭)는 그대로다.

요청의 "REST API를 따르면서"는 **화면 구성 · 이동 순서와 API 동작은 그대로 두고, API 응답 값만 보여 준다**는 뜻으로 읽었다(CLAUDE.md 코드 규칙). 이 해석이 다르면 알려 주면 바로 고친다.

## 후보: 3번 시안을 어디까지 옮길지

| | 가. CSS만 덧씌움(화면 구조 그대로) | 나. 시안의 화면 구성까지 새로 만듦 |
| --- | --- | --- |
| 하는 일 | 색 · 모서리 · 글꼴 · 간격 · 위치만 시안 규칙으로 바꾼다 | 시안의 설비 20대 타일 지도, 교대 KPI, 로그 같은 패널을 새 화면으로 만든다 |
| 화면 순서 · API | 그대로 | 새 화면 · 새 데이터가 필요하다 |
| 명세 | 바꿀 것 없음 | 명세에 없는 기능이라 먼저 명세를 바꿔야 하고, 홈 API(`/api/tech/home`)에 설비 전체 상태 · KPI · 로그가 없다 |
| 4개 후보 비교 | 같은 화면을 보여 주는 공정한 비교 | 후보마다 보여 주는 정보가 달라 비교가 안 된다 |

## 결정

**가.** 화면 · 버튼 · 이동 순서(DOM과 클래스)는 바꾸지 않고, 시안의 시각 규칙을 CSS로 옮긴다.
시안의 설비 타일 지도 · 교대 KPI · 로그 패널처럼 API가 주지 않는 정보는 만들지 않는다(화면은 API가 준 값만 보여 준다).

## 새 C · 산업 관제형 규칙

시안의 한 줄 컨셉은 "화색은 정상, 색은 이상. 현장에서 3초 안에 판단하는 관제형 화면"이다.

| 시안의 규칙 | 이 화면에서 옮기는 방법 |
| --- | --- |
| 정상은 회색, 색은 이상일 때만(ISA-101 High-Performance HMI) | 바탕 `#16191d`, 패널 `#1e2226`, 정상 `#5b636d` 회색. 경계 이탈은 빨강 `#e5484d`, 주의 · 승인 필요(C등급 · 호출)는 주황 `#f5a524`, 완료는 초록 `#56d364`, 선택 · 행동 · AI는 하늘 `#36c5f0` |
| 숫자는 고정폭, 기준과 함께 | 센서 값 · 퍼센트 · 건수 · 시각 · 기록 번호는 고정폭 글꼴(`--mono`). 이 후보는 본문 글꼴을 바꾸지 않는다. 시안의 본문 IBM Plex Sans KR은 [0006](0006-AB-테스트용-글꼴-후보.md)의 글꼴 메뉴에서 고르고, 숫자는 JetBrains Mono가 있으면 그것을, 없으면 시스템 고정폭 글꼴을 쓴다 |
| 작업 단계는 하단 고정 레일 | 진행 표시(`.ap-step`)를 화면 맨 아래에 붙은 5칸 레일로 옮기고 현재 단계는 위쪽 하늘색 줄 |
| 한 화면 다중 패널, 정렬은 엄격 | 카드 모서리 0, 1px 테두리, 패널 간격 8px, 패널 제목은 작은 고정폭 라벨 |
| 큰 결과 버튼, 유일한 강조 테두리 | 결과 버튼 높이 96px, 큰 주 버튼 72px 하늘색. 다음 점검 카드만 하늘색 테두리 |
| 현재 알람은 상단 빨간 띠 | 상단 현재 알람(`.tb-ctx`)을 가로로 늘린 빨간 띠, 앞에 `ALARM` 라벨 |
| 파트장 앱 | 왼쪽 메뉴는 그대로 두고 같은 색 · 각진 모서리 · 고정폭 숫자, 표는 촘촘한 줄 |
''다크' 버튼을 숨긴다 |

## 바뀌는 것 / 바뀌지 않는 것

- 제거: `variants/b-field.css`(현장 터치형), `variants/c-workspace.css`(업무 도구형)
- 이름 바꿈: `variants/d-bento.css` → `variants/b-bento.css`, 선택자 `[data-variant="d"]` → `"b"`
- 추가: `variants/c-industrial.css`(새 C)
- 변경: `variant.tsx`(후보 목록 A · B · C, C에서는 다크 모드 설정을 쓰지 않음), `dark.css`(옛 b · c 보정 제거, 옛 d 보정을 b로)
- 그대로: 화면 구성 · 버튼 · 이동 순서, 다크 모드 기능(A · B에서), E 조장님 원본 링크, 글꼴 메뉴

## 영향

- 전환 막대와 주소: `?v=b`는 이제 플로팅 벤토형, `?v=c`는 산업 관제형이다. 옛 `?v=d`는 A로 열린다.
- README · 명세 · CHANGELOG · 결정 기록 0004의 후보 이름을 고친다.
