# 0002. 정비자·파트장 앱 디자인을 대시보드 디자인 언어로 통일

- 상태: 일부 대체됨(→ 0003). 색·글꼴 결정은 유효, 화면 틀·배치 변경은 되돌림
- 날짜: 2026-10-16
- 작성: 문선웅
- 관련: `packages/ui/src/styles/theme.css`, `apps/dashboard/src/styles/base.css`

## 배경

정비자·파트장 앱은 기능 확인용 기본 디자인이었다. 파란 강조색, Noto Sans, 고정 크기 화면 틀(정비자 1080 × 740, 파트장 1280 × 620)을 회색 바탕 위에 띄우는 방식이었고, 스타일이 세 파일(약 54KB)에 문서용 규칙과 섞여 있었다. 대시보드는 이미 별도 디자인(흰 바탕, 회색 중립색, 주황 강조, Pretendard)이 있어서 같은 서비스인데 화면마다 모양이 달랐다.

## 후보

| | A. 기존 디자인 유지 | B. 새 디자인 체계를 따로 만들기 | C. 대시보드 디자인 언어로 통일 |
| --- | --- | --- | --- |
| 하는 일 | 색만 일부 조정 | 새 토큰·컴포넌트 설계 | 대시보드 토큰을 기준으로 정비 화면 전체를 다시 그림 |
| 서비스 일관성 | 화면마다 다름 | 대시보드도 다시 바꿔야 맞음 | 세 앱이 같은 모양 |
| 작업량 | 작음 | 큼 | 중간 (테마 파일 하나) |
| 화면 코드 영향 | 없음 | 클래스 구조까지 바뀔 수 있음 | 클래스 이름 그대로, CSS만 교체 |

## 결정

**C. 대시보드 디자인 언어로 통일.** 기존 스타일 세 파일을 지우고 `packages/ui/src/styles/theme.css` 하나로 새로 작성했다.

## 디자인 내용

| 요소 | 기존 | 바뀐 모양 |
| --- | --- | --- |
| 글꼴 | Noto Sans KR | Pretendard (대시보드와 같음) |
| 강조색 | 파랑 `#2457f5` | 주황 `#ea580c`: 현재 단계, 1순위 원인, 알림 숫자, 지금 할 절차 |
| 주 버튼 | 파랑 바탕 | 검정 `#18181b` 바탕 (대시보드 주 버튼과 같음) |
| 중립색 | 푸른 회색 | zinc 회색 (`#f7f7f8` · `#e4e4e7` · `#52525b` · `#71717a`) |
| 모서리 | 16px 카드 · 10~12px 버튼 | 12px 카드 · 6~8px 버튼 |
| 그림자 | 카드마다 | 카드는 테두리만, 그림자는 떠 있는 창(알림 패널·모달)에만 |
| 화면 틀 | 고정 크기 틀을 회색 바탕 가운데에 | 브라우저 전체를 쓰고, 본문은 최대 1320px로 가운데 정렬. 900px 이하에서는 한 열 |
| 파트장 메뉴 | 남색 사이드바 | 대시보드와 같은 밝은 사이드바, 현재 메뉴는 흰 카드 + 주황 아이콘 |
| 진행 표시 | 완료 초록 · 현재 파랑 | 완료 검정 · 현재 주황 |
| 상태 칩 | 사각 칩 | 둥근 칩, 빨강·주황·초록 상태는 점 표시 (대시보드 배지와 같음) |
| 잠긴 버튼 | 🔒 이모지 | 자물쇠 아이콘 |
| 모달 | 화면 틀 기준 고정 위치 | 화면 가운데, 높이를 넘으면 안에서 스크롤 |

권한 등급 A~D 배지는 의미가 정해진 색(A 초록, B 파랑, C 주황, D 빨강)이라 색 체계를 유지하고 톤만 맞췄다.

## 이유

- 같은 서비스의 세 화면이 같은 모양이어야 사용자가 하나의 서비스로 읽는다.
- 대시보드에서 이미 정한 토큰을 기준으로 삼으면 새로 정할 값이 적다.
- 클래스 이름을 그대로 두고 CSS만 바꿔서 화면 로직과 테스트(85개)를 건드리지 않았다.

## 영향

- 삭제: `packages/ui/src/styles/guide-a.css`, `direction-guide.css`, `past-adjust.css`
- 추가: `packages/ui/src/styles/theme.css`
- 두 앱의 `index.html`에 Pretendard 글꼴 링크 추가, `main.tsx`는 `theme.css` 하나만 불러옴
- 정비자 로그인 화면의 고정 높이(740px) 인라인 스타일 제거
